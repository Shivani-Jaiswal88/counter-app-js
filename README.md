## Counter App
The goal of this project is simple: **increase, decrease, and reset the counter value using buttons.**
This project was created as a practice project to improve my understanding of **HTML, CSS, JavaScript, DOM manipulation, and events**.
[live link](https://shivani-jaiswal88.github.io/counter-app-js/)

# Features

1. Increase the counter value
2. Decrease the counter value
3. Reset the counter value
4. Button click interactions
5. JavaScript event handling
6. Simple and clean UI

# Technologies Used

1. HTML5
2. CSS3
3. JAVESCRIPT
